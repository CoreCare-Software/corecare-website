# CoreCare Platform 1.6.1 — Reliable owner support access

Repairs the owner workflow for opening linked product organisations in audited support mode.

- Clears a stored product error as soon as a live organisation refresh succeeds.
- Validates the required support reason before opening a new browser window.
- Displays support-session failures using the correct error treatment.
- Refreshes deployed asset and version metadata consistently.

No database migration is required.
