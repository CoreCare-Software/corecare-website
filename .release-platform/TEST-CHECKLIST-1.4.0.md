# CoreCare Platform 1.4.0 Test Checklist

## Deployment
- [ ] Version shows 1.4.0
- [ ] No red error toast appears
- [ ] Executive Dashboard loads

## Ticket queue
- [ ] Tickets page opens and KPI totals display
- [ ] Search works by number, subject and organisation
- [ ] Product, status, priority and assignee filters work
- [ ] Unassigned filter works

## Ticket workflow
- [ ] Create a test ticket
- [ ] Open it and change priority, status and assignee
- [ ] Set a target response date
- [ ] Link and unlink an incident where available
- [ ] Add a customer reply and an internal note
- [ ] Log 5 minutes of time
- [ ] Upload, download and remove a file under 2 MB
- [ ] Mark resolved, reopen, then close the ticket

## Organisation and regression
- [ ] Product pages still list organisations
- [ ] Organisation monitoring shows related tickets
- [ ] Active Support Sessions works
- [ ] Staff, Audit Log and Platform Settings load
- [ ] Sign out and sign in again
